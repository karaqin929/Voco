## 架构变化

```
旧: 浏览器 ↔ FastAPI ↔ JSONL 文件
新: 浏览器 ↔ Supabase (Auth + PostgreSQL + RLS)
```

- FastAPI 后端降级为纯静态文件服务
- 登录/数据库全部走 Supabase
- 数据不再依赖 Render 磁盘，云端持久化

## 数据表

| 表 | 用途 |
|---|---|

| errors | 纠错（语法/发音） |

| progress | 学习进度统计 |
| reports | 日报归档 |
| user_config | 用户设置 |

## 技术要点

- Supabase `anon key` 前端直连，RLS 保证安全
- `signInWithOAuth` + `prompt: select_account` 多账号切换
- `sb.from().select().eq('user_id', uid)` 数据隔离
- `upsert` + `onConflict` 实现 progress 增量更新

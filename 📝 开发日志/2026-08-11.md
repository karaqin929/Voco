## Bug 修复

| 问题 | 修复 |
|------|------|
| 用户名不自动保存 | `#setting-username` 加 `input` 事件 + 800ms debounce 写 Supabase |
| 错误模式不可点击 | `showErrorDetail(pattern)` 可点击展开对应错误 |
| Render 黑屏 | `#voco-loading` 占位 + 🐻弹跳动画 |
| TTS 声音太机械 | `getBestVoice()` 优先 Google US English / Samantha |
| 主题颜色太像 | 4套 palette 完全重设计：暖调珊瑚橙 / 沙滩金棕 / 大海冷蓝 / 冰天薰衣草 |
| 登录态丢失 | Supabase `onAuthStateChange` + `getSession()` 自动恢复 |

## v3.0 架构

```
Tab 结构:
├── 🏠 首页
│   ├── 👋 问候语 + 🔥 streak 打卡
│   ├── ① 概览 donut + 4维进度条 + 统计pill
│   ├── ② 每日任务 (3 quest + 进度条)
│   ├── ③ 日报详情 (折叠)
│   ├── ④ 🐻 热力图 (横向滑动)
│   └── 📊 Stats Grid + 🎯 练习流程
├── 📝 单词
│   ├── SM-2 复习入口
│   ├── 闪卡复习模式
│   └── 词汇库 + 搜索
├── 🗣️ 口语
│   ├── 影子跟读模式
│   └── 表达卡片库 + 搜索
└── 👤 我的
    ├── 个人资料 (🐻 + Lv + XP)
    ├── 成就徽章
    ├── 导入日报

    └── 数据导出 + 退出
```

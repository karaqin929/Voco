## 架构要点

```
首页布局（从上到下）:
├── 👋 问候语 + 🔥 Streak 打卡
├── 📋 智能任务卡片（最多5张）
├── 📊 今日报告 / 🎯 引导流程
├── 📈 Stats Grid（练习/单词/纠错/坚持）
├── 📥 导入日报（折叠）
└── 📅 热力图（折叠）
```

## 任务卡片逻辑

| 优先级 | 触发条件 | 卡片 | 点击行为 |
|--------|----------|------|----------|
| 1 | 今日有日报 | 📊 查看今日报告 | 滚动到报告 |
| 2 | SM-2 到期词 > 0 | 🃏 复习单词卡 (N) | → 复习 tab |
| 3 | 未纠错 > 0 | 🔧 查看纠正建议 (N) | → 词汇 tab |
| 4 | 今日新词 > 0 | 📝 今日新词 (N) | → 词汇 tab |
| 5 | 句型库 > 0 | 🎤 影子跟读 | → 复习 tab |
| 6 | 3/7/14/21/30... | 🎉 里程碑 | 仅展示 |
| 7 | 今日无日报 | 🎯 开始今日练习 | 滚动到流程 |
| - | 全完成 | ✅ 全部搞定 | 仅展示 |

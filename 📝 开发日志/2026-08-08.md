## 踩坑记录

1. **FastMCP 与 FastAPI 路由冲突** — `from mcp.server.fastmcp import FastMCP` 会拦截所有 HTTP 请求返回 `{"error":"not found"}`。解决方案：从 Render 版 server.py 中移除 FastMCP，保留纯 FastAPI。MCP 仅用于本地。

2. **StaticFiles mount 覆盖路由** — `app.mount("/", StaticFiles(...))` 会让静态文件中间件接管根路径，导致 API 路由失效。解决方案：改为显式路由逐个处理静态文件。

3. **Emoji 文件夹名在 Linux 上** — Render Linux 无法识别 `🖥️ 前端/` 等 emoji 路径。解决方案：前端文件复制到 `⚙️ 后端/` 同目录，`FRONTEND_DIR = SCRIPT_DIR`。

4. **Render URL 被占用** — `voicelog.onrender.com` 已被他人注册，实际分配地址为 `kks-voicelog.onrender.com`。

5. **pyyaml date 对象不可序列化** — pyyaml 解析 `date: 2026-08-08` 返回 `datetime.date` 对象。添加 `_safe_json()` 自定义编码器处理。

6. **mcp/fastmcp 未加入 requirements.txt** — 初次部署失败，补充依赖后解决。

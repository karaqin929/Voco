## 🔑 核心机制 1：v84 七级字号阶梯（唯一合法字号）

| 层级 | 大小 | 实现 | 用途 |
|---|---|---|---|
| L1 · micro | 11px | `text-[0.6875rem]` | 徽章、按钮小字、进度标签、打卡状态、日历日期 |
| L2 · caption | 12px | `text-xs` | 辅助说明、计数、提示语、音标 |
| L3 · body | 14px | `text-sm` | 正文、卡片内容、按钮、副行、释义、banner |
| L4 · title | 16px | `text-base` | 区块标题、空态标题 |
| L5 · headline | 20px | `text-xl` | **所有统计数字**、卡片主句、词卡正面、句型卡正面 |
| L6 · hero | 24px | `text-[1.5rem]` | 评分环中心数字、卡片背面正确答案 |
| L7 · brand | 34px | 2.125rem | 仅登录页品牌标题 |

- **数字两级化**：普通统计数字一律 L5（20px bold），评分环中心 L6（24px）——此前四指标 15px / 三卡 22px / 时长 20px / 错误计数 18px / 评分环 26px 各说各话，全部归位
- **卡片正/背面分层**：正面主句 L5，背面正确答案 L6（due 卡背面 17px 与句型卡背面 24px 不一致已拉齐）
- **rem 化原理**：设置页「文字大小」靠 `html font-size` 缩放（16×1 / 1.07 / 1.15），Tailwind 标准类（xs/sm/base/xl/2xl）本就是 rem 单位，但 60+ 处 `text-[NNpx]` 任意值与 style.css 的 px 不响应 → 全部改 rem 后三档真正全局生效，间距仍为 px 不受影响
- 豁免：图标字符字号（.lib-search-icon 14px / .login-icon 72px / ⏳ text-2xl）非文字不参与阶梯
- **新增 UI 严禁再写 `text-[NNpx]`**，仅三个合法 rem 任意值（0.6875 / 0.875 / 1.5）——已写入 CLAUDE.md 铁律

## 🔑 核心机制 2：v85 统计卡口径统一（数字 = 列表）

**Bug 1 根因**：v82 日期路由只修了历史视图（携带 `_viewDate`），今日场景点击「核心句型」无任何 date 参数 → 句型页 `_ctxDate=null` → 走 `getDueSentencesQueue`（SM-2 到期混合，截断 15），与统计卡数字（当日日报 5 句）分裂。

**修复**：`renderContentCards` 新增 `shadowDate = historyMode ? _viewDate : getLocalToday()` → 核心句型卡 `navigateShadowing(undefined, undefined, shadowDate)`；`navigateShadowing` / `handleRoute(/shadowing 分支)` / `loadSpeak` 三处放开「today 排除」（`_ctxDate = dParam || null`）。**无 date 的 `navigateShadowing()` 仍是待办打卡专属入口**（到期队列 15 句，语义不变）。

**Bug 2 根因**：统计卡 `todayNewWordsCount = realVocab.filter(v => v.isNewToday).length`（词库打标口径，含 DB 行残留旧打标）vs 列表页 `_reportParsed.vocabulary`（日报解析口径）——两个口径分裂致首页 8 / 列表 6。

**修复**：`todayNewWordsCount = reportParsed.vocabulary.length`（与 `getFilteredVocab` today 分支、历史视图分支三方同源）；`stampDailyTags` 无条件重算 `isNewToday = date_added === 今日`（`mergeReportVocab` 在打标后运行，日报词重新打 true 不受影响）。

**重点纠错卡审计结论（同源无误，无需修）**：数字 = 列表 = `grammar + pronunciation` 同批数据。两个口径说明：① JSON 日报 `type: expression` 条目不进纠错卡（归入 patterns → 入库句型库，首页「地道表达」计数），符合 v83 模板契约；② 无今日日报时数字 0 但点进去显示历史错题本（errors 表积累），为「今日增量 vs 错题本全量」的既有设计语义。

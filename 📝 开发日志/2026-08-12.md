## 🐛 核心 Bug：全局状态污染

**症状：** 单词页点「今日新词」→ 切到口语页 → 显示错误的专注模式「正在专注练习：今日新词」

**根因：** `switchWordsView()` 调用 `navigateToTab()` 写入全局 `_activeFilter`；`loadSpeak()` 读取被污染的全局状态。

**修复（5 处）：**

| # | 位置 | 改动 |
|---|------|------|
| 1 | `switchWordsView()` | 移除 `navigateToTab()`/`clearFilter()` 调用，只用 `_wordsFilter` + 直接 render，URL 用 `wordsView` 参数 |
| 2 | Tab bar handler | 新增守卫：手动切 tab 时清空 `_activeFilter` |
| 3 | `navigateToTab()` | `.click()` 前后包裹 `_navigatingViaProgram = true/false` |
| 4 | `popstate` handler | 同样包裹 flag，防止浏览器前进/后退误清 |
| 5 | 新增全局 flag | `let _navigatingViaProgram = false` |

**架构原则确立：**
- 单词页 Tab 状态（`_wordsFilter`）与口语页专注过滤（`_activeFilter`）是两个独立变量
- 口语页过滤参数**只能**由首页建议/靶点的 `navigateToTab` 触发
- 手动切 tab = 干净重置

## 📐 Card D 「今天需要提升」终版结构

经过三轮迭代（flex 重写 → 独立卡片 → 数据结构化），最终规范：

**数据模型：** 每条错题拆三个字段（不再塞进一个 `detail` 字符串）：

```js
{ issue: '表达纠正',
  wrong: 'I have went to three interviews last month.',
  correct: 'I have gone to three interviews last month.',
  explanation: '过去时态与完成时混淆：现在完成时需用 have + 过去分词' }
```

**渲染铁律：一条错题 = 一张圆角卡片**

```
┌─────────────────────────────────────────┐
│ 🏷️ 表达纠正（amber 标签）                │
│ ~~I have went to three...~~  红色删除线   │
│ → I have gone to three...  绿色加粗       │
│ 过去时态与完成时混淆：...   灰色小字       │
│                          [查看纠错 →]    │
└─────────────────────────────────────────┘
```

- 外层 `flex items-start justify-between gap-4`
- 左侧 `flex flex-col gap-1.5 flex-1`（错句在上、正句在下、解释垫底）
- 右侧按钮 `shrink-0 mt-1`，顶部对齐，永不换行
- 严禁绝对定位/浮动；严禁把一条错题拆成多张卡片
- 旧 `detail` 字符串保留为 legacy fallback（兼容已入库历史数据）
